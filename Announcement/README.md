# AntiAFK-RBX Preview Announcements

`announcement.preview.json` is fetched on startup by preview builds (alpha/beta/rc) and opens `https://agzes.github.io/go/to/antiafk-rbx/preview-notify`.

```json
{
    "enabled": true,
    "notify": false,
    "icon": "\uE76E",
    "iconColor": "#ffffff",
    "title": "Title",
    "description": "Optional details"
}
```

For stable builds and full documentation, see the `main` branch.
